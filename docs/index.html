Your server's own Valorant leaderboard.

N9 Tracker is a Discord bot that lets players link their Riot account with Riot Sign-On, check their recent matches, and see how they rank against everyone else in their server.

Add to Discord See how it works

Free. No ads. Only players who sign in with Riot are ever tracked.

Features

Everything happens through slash commands in your server.

🔗 Link with Riot

/valorant add sends a private "Log in with Riot" link. You prove you own the account; we never see your password.

🎯 Recent matches

/valorant recent shows your latest games: map, agent, K/D/A and result.

🏆 Server leaderboard

/valorant leaderboard ranks the opted-in players in your server, kept separate from every other server.

🗑️ Leave anytime

/valorant remove unlinks your account and deletes your data from that server immediately.

Sign in on Riot's website (RSO)

The link opens Riot Sign-On on Riot's own domain. The user logs in and approves N9 Tracker. Riot then redirects back to N9 Tracker with proof of which account it is.

auth.riotgames.com → (Riot's official sign-in and consent screen)
Handled entirely by Riot
  • The user enters their credentials on Riot's page only. N9 Tracker never sees them.
  • The user approves sharing their Riot ID with N9 Tracker.
  • Riot redirects to N9 Tracker's callback, which reads the account's PUUID and Riot ID.

Riot APIs used

Official Riot API only. No scraping, no unofficial APIs.

APIUsed for
RSO (OAuth)Proving the user owns the Riot account they link
ACCOUNT-V1Riot ID and PUUID, and the account's active shard
VAL-MATCH-V1Match list by PUUID and match details, for linked players only
VAL-CONTENT-V1Agent, map and game-mode names
VAL-STATUS-V1Server status and maintenance notices
